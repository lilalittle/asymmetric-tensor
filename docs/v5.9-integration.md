## Author changes and intentional migration

The exact stable-v5.8-to-v5.9 named inventory changes 473→475: two added, none
removed, only `magnitude_anomaly_log10_pos` changed. There are still 75 declaration
docstrings, with one corrected Christoffel description. Both structures, all
three explicit instances, imports and section-variable context are unchanged.

- `optical_path_closed_form_antiderivative` combines two supplied `HasDerivAt`
  premises, gives the zero value, the derivative of the **unscaled** primitive
  `z/2 + ln(2z+1)/4`, and its scaled derivative-value algebra for `2z+1 ≠ 0`.
- `magnitude_anomaly_log10_pos` changes from `A ∧ B` to `A ∧ C ∧ B`: base-10
  modulus identity, explicit `(5 / ln 10) * ln(r_opt/r_true)` bridge, positivity.
  Old positivity consumers must use `.2.2`, not `.2`. `V59Migration.lean` provides
  an exact old-contract reconstruction and exercises each projection.
- `born_infeld_general_determinant_isomorphism` proves the full 3D determinant,
  its `(E · B)²` term, cleared polynomial and necessary-and-sufficient equality
  criterion against `det(U_sym)`, assuming nonzero `alpha_s`. Its final numeric
  polynomial benchmark is `-15/16` for unit admittance and parallel fields.
  Separate regressions evaluate an actual nonunit-admittance matrix.
- Corrected comments distinguish natural-log cancellation, K/Omega/E dimensions,
  constitutive shear load, cavitation scope and pointwise connection reduction.

The raw upload, named declarations, proof tokens and declaration docstrings are
