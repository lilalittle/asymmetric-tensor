Compared with v5.6, five bounded names are added and ten existing declaration
token sequences change; none are removed. `DynamicClebschFields` is an additional
structure outside that named count. Compared with stable v5.0, 36 bounded names
are added, one is removed and 22 existing token sequences change. These counts
include lexical changes and do not classify every difference as semantic.

The intentional migration includes:

- **Dimensions:** `UnitDim.L/V/S` is replaced by `K/Omega/E`; the constructor,
  derived `DecidableEq`/`Repr`, and `Mul`/`Div`/`HPow` instances use the new
  coordinates. The author's basis relation maps `(L,V,S)` to
  `(-(L+V), V-S, S)`. Old projection names are not retained as aliases.
- **Dynamic state:** `DynamicClebschFields` has eight scalar-field projections
  and a conservation field. `vacuum_clebsch_witness` proves inhabitance, opaque
  `dyn_state` selects the active configuration, and the eight formerly body-less
  opaque fields become definitions projecting from it. `covariant_conservation`
  changes from an axiom to a theorem with the same displayed dynamic-field scope.
- **Spectra:** new eigenvectors and `schwinger_zero_slip_aligned_bridge` connect
  the shifted full `U_hat` to the aligned matrix under explicit zero slip and
  axial-vorticity assumptions. The nonzero-slip counterexample remains. The
  older `schwinger_limit_eigenvalues` API expands relative to v5.0; its comments
  now identify the transverse-block and aligned-root results accurately.
- **Optics:** `tensor_four_effects_unification` explicitly takes `alpha_s` and
  `alpha_s = alpha_g * alpha_a`, returning seven conjuncts. Pressure-only
  refraction through `U_hat alpha_g` remains distinct from the combined tensor.
  BAO and Hubble comments describe the algebraic conclusions rather than claiming
  missing integration or derivative bridges.
- **Mass and galactic results:** the removed v5.0
  `phase_locked_vortex_rest_mass_generation` is replaced by the author's
  `phase_locked_frobenius_rest_mass_pos` with explicit load, energy, mass and
  positivity premises. Added phase-lock, horizon, reflection/plane-stress,
  bounded-annulus and boundary-matching results retain their stated conditions.

These changes are author-source changes, not integration repairs. The empty
custom-axiom policy does not imply absence of ordinary logical axioms, arbitrary
field conservation, a nontrivial physical solution or completion of the broader
manuscript research program.
